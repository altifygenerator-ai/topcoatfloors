# Top Coat Texas — Flooring Website

Next.js App Router + React + TypeScript client-facing homepage design demo for Top Coat Texas, Houston, TX. Ready for full website development.

## Running locally

`npm install`

`npm run dev`

## Deployment

This GitHub repo is intended to be connected to a separate Vercel Next.js project. Each push to `main` redeploys.

## Design demo status
